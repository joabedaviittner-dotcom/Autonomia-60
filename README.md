## Sobre o projeto

O **Autonomia 60 Mais** é um projeto independente, idealizado e desenvolvido por Joabe, com o objetivo de promover a inclusão e a autonomia digital de pessoas com 60 anos ou mais.

A plataforma busca facilitar o aprendizado tecnológico por meio de conteúdos educativos, tutoriais, ferramentas acessíveis e orientações sobre segurança digital.

O projeto foi criado para ajudar pessoas idosas a utilizarem a tecnologia com mais independência, confiança e segurança.
